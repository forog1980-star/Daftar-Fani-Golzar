# مجموعه فرم‌ها و ابزارهای دفتر فنی اداری گلزار شهدای تهران

**وضعیت:** پیش‌نویس برای بررسی و اصلاح؛ فاقد اثر مصوبه یا دستورالعمل اجرایی تا زمان تأیید مرجع ذی‌صلاح.

## فایل‌ها
- `01-فرم‌های-استاندارد-دفتر-فنی.xlsx` — شش فرم مستقل به‌همراه شیت راهنما.
- `02-بانک‌ها-و-دفاتر-مدیریتی.xlsx` — چهار شیت بانک نیازهای فنی، بانک شناسنامه پروژه‌ها، دفتر کنترل بودجه و اعتبارات و گزارش پایش دوره‌ای.

## اصول استفاده
۱. برای هر نیاز کد پیگیری یکتا و برای هر پروژه کد پروژه مستقل ثبت شود.
۲. همه مبالغ با واحد ثابت ریال ثبت شوند.
۳. اعتبار مصوب، تخصیص‌یافته، تعهدات، صورت‌وضعیت ارائه‌شده، مبلغ تأیید فنی/ناظر، مبلغ تأیید مالی و پرداخت واقعی در فیلدهای جداگانه درج شوند.
۴. دفتر فنی مسئول نیازسنجی، تعریف فنی، برآورد، اولویت‌بندی کارشناسی، پیشنهاد و پایش است؛ تشریفات معامله، قرارداد، تعهد مالی و پرداخت با مراجع ذی‌صلاح است.
۵. ثبت فرم تغییر، به‌تنهایی مجوز اجرای تغییر نیست.
۶. مدل اولویت‌بندی ۱۰۰ امتیازی با وزن‌های ۳۰، ۲۵، ۲۰، ۱۰، ۱۰ و ۵ صرفاً پیشنهاد پژوهش ۰۲ است.
۷. فونت سلول‌ها روی **B Zar** تنظیم شده است؛ برای نمایش یکسان باید این فونت روی رایانه نصب باشد.
