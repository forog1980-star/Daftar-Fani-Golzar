# بودجه و اعتبارات

در این بخش پیشنهادهای بودجه، متمم‌ها، وضعیت مصوب و تخصیص‌یافته، تعهدات، پرداخت‌ها و گزارش‌های پایش اعتبار نگهداری می‌شود.

**قاعده ثبت:** اعتبار مصوب، تخصیص‌یافته، تعهدشده، صورت‌وضعیت تأییدشده، پرداخت‌شده و مانده در ستون‌های جداگانه ثبت شوند. اسناد مالی محرمانه فقط با رعایت سطح دسترسی سازمانی نگهداری شوند.
